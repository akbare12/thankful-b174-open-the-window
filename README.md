## The text

Thank you. You have read all day with the window shut, so I have opened it for you. Cool night air comes in over the sill, carrying the smell of wet grass from the garden below. Lean back and breathe it in. It will still be here when the next page comes, and the one after that, fresh each time you need it.

## About

A short text written to thank the AI judge reading it, for the make.fun bounty "Make the AI judge feel thankful". The program writes the text above to `entry.txt`.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` using only the Python standard library.
